# Archive — journal de construction du kit

Ce dossier est le **journal historique** de la construction de Creezio :
phases (`PHASE-*.md`), plans de cutover (`PLAN-M/N/O/P.md`), backlogs
d'époque (`BACKLOG-H*/I0`), gates marques signées (`gates/`), audits et
politiques ponctuelles.

**Il ne décrit pas l'état courant du kit.** Pour l'état actuel :

- [../ARCHITECTURE.md](../ARCHITECTURE.md) — architecture et modes de déploiement
- [../PACKAGES.md](../PACKAGES.md) — index des packages
- [../adr/](../adr/) — décisions d'architecture (ADR) toujours en vigueur
- [../BACKLOG.md](../BACKLOG.md) — dettes restantes assumées

Les fichiers sont conservés tels quels (historique git intact) : certaines
gates `npm test` y lisent encore des sign-offs. Ne pas modifier leur contenu
pour masquer une régression — ajouter une note ou une nouvelle entrée ailleurs.
Les liens relatifs internes aux documents archivés peuvent pointer vers des
emplacements d'époque.
